# SoC 集成与接口契约

集成阶段的缺陷九成来自**契约没定死**：地址空间谁占哪一段、outstanding 给多深、哪个域跨到哪个域、中断怎么清。这些问题在模块级看不出来，到顶层一起爆。这一章按"先定契约，再接逻辑"的顺序走。

## 1. 地址映射

**先出表，再接译码器。** 地址表是 CPU、驱动、验证、DFT 四方共同的事实，改一次要通知四方。

| 区块 | base | size | 对齐要求 | 访问属性 | 归属 master | 备注 |
|---|---|---|---|---|---|---|
| BOOT_ROM | 0x0000_0000 | 64 KB | 4 KB | RO / cacheable | CPU | 复位向量 |
| SRAM0 | 0x2000_0000 | 256 KB | 4 KB | RW / cacheable | CPU, DMA | 双口 |
| PERIPH | 0x4000_0000 | 1 MB | 4 KB | RW / strongly-ordered | CPU | APB 桥后 |
| DDR | 0x8000_0000 | 2 GB | 1 MB | RW / cacheable | 全部 | 主存 |

规则：

- **size 必须是 2 的幂，base 按 size 对齐**。不满足就必须用区间比较译码，面积和时序都差一档，且容易漏边界。
- 地址空间**不许留空洞**却没有 default slave。空洞读到的是总线挂死（AXI 无响应 → 主机超时 → 整个系统看上去随机死机）。
- **必须有 default slave**，未命中任何区间时返回 `DECERR`（读）或不响应写但回 `BRESP=DECERR`。这条是集成必查项，也是最常被省掉的一条。
- 同一地址被两个 slave 覆盖 = 错误，不是"优先级问题"。
- 保留区（Reserved）要显式列出，不要让"没写"等于"没占"。

**译码器结构**：slave 数 ≤ 8 时用区间比较（`addr[31:20] == base[31:20]`）一把出 one-hot，延迟 1–2 级；slave 数多或区间不规则时做两级译码，第一级按高位分段，第二级段内比较。译码逻辑挂在**地址通路上**，它的延迟直接进 AXI 的 `awvalid→awready` 路径，别在这里堆优先级链。

## 2. AXI 接入与 outstanding

**outstanding 深度是算出来的，不是拍的。** 用 Little's Law：

```
需要的 outstanding 字节数 B = 目标带宽 BW × 往返延迟 RTT
需要的 outstanding 笔数   N = B / 每笔突发字节数
```

例：目标 12.8 GB/s，主机到从机的往返延迟 200 ns，突发长度 64 B（AXI4 的 8 拍 × 8 B）：

```
B = 12.8e9 × 200e-9 = 2560 B
N = 2560 / 64 = 40 笔
```

所以 `AW/W` 与 `AR` 各要给到 ≥ 40 的深度。给 8 笔，带宽只能到 `8×64/200ns = 2.56 GB/s`——差 5 倍，而且报告上看不出任何异常，只会表现为"内存带宽上不去"。

**判断 outstanding 配够没有的实测方法**：跑一个纯读的 memset 类负载，看 `AR` 通道的平均占用率。低于 70% 说明深度不够或从机反压太狠。

| 配置项 | 取值依据 | 配错的后果 |
|---|---|---|
| `AR/AW` 深度 | 上面的 Little's Law | 带宽直接按比例打折 |
| `W` 通道深度 | 通常与 AW 对齐，写合并好可浅 | 写吞吐受限 |
| 突发长度 | 不超过 4 KB 边界（AXI 硬约束） | 跨 4 KB 要拆，拆了带宽掉 |
| 数据位宽 | 与从机数据通路同宽，避免 upsizing | 位宽转换器加延迟和面积 |
| ID 位宽 | = log2(并行事务数) | 少了事务乱序，多了面积浪费 |

**必须显式确认的三件事**：

1. **是否允许乱序**。多 ID 才有乱序，单 ID 严格顺序。DMA 想并发就得给多 ID，但下游要有重排或按 ID 独立缓冲，否则乱序到达的响应没地方放。
2. **写响应是否必须等**。`B` 通道不回，写缓冲占着不放，几拍后写通路就堵死。
3. **4 KB 边界**由谁拆。主机侧拆比从机侧拆便宜，别让一个不认识的从机去处理跨界突发。

**AXI 三个通道的 handshake 各自独立**，`AWVALID`、`WVALID`、`BREADY` 不能假设同拍。只在 `AWVALID && AWREADY` 那拍采地址、在 `WVALID && WREADY && WLAST` 那拍收完数据，这两件事之间可以有任意拍间隔。

### AHB / APB 的接入要点

能力声明里有 AHB/APB，但两者与 AXI 的接入逻辑差别很大，缩水成"也是总线"会出事：

| 项 | APB | AHB |
|---|---|---|
| 定位 | 低速寄存器配置访问 | 中速单 master 管线化访问 |
| 访问时序 | 两拍：`PSEL`→`PENABLE`，无 outstanding | `HTRANS`（IDLE/NSEQ/SEQ）流水，`HREADY` 反压 |
| 反压 | 无——从机必须一拍就绪，慢外设要自己做 stretch | 有，`HREADY` 拉低整条管线停 |
| 突发 | 无 | 有（HBURST），但不像 AXI 那样乱序 |
| 典型坑 | 把慢寄存器挂在会被高频访问的 APB 段上 | `HREADY` 组合直通造成长组合链；SPLIT/RETRY 响应没实现却译码了 |

**AXI→AHB/APB 桥是降级点，三件事在桥上定死**：outstanding 降为 1（桥内一次只挂一笔）；AXI burst 拆成 AHB 的 HBURST / APB 的逐笔访问；4 KB 边界的拆分责任落在桥上。这三条不写进 spec，验证方不知道要测桥的反压与边界场景。

## 3. 时钟域与复位域

**先画域图，再写代码。** 域图要标：有几个时钟、各自频率与来源（PLL 分频 / 外部晶振 / 门控后）、跨域点在哪、用什么同步方案。

| 跨域类型 | 方案 | 不许用 |
|---|---|---|
| 单 bit 电平（如 `enable`） | 两级同步器 | 直接进组合逻辑 |
| 单 bit 脉冲（如 `done`） | 脉冲展宽 + 同步，或 toggle 握手 | 直接两级同步（窄脉冲漏采） |
| 多 bit 计数/指针 | 格雷码 + 两级同步 | 各 bit 独立同步 |
| 多 bit 数据 | 异步 FIFO / 握手同步 / DMUX | 各 bit 独立同步 |
| 复位 | 异步复位、同步释放（每域各一个 synchronizer） | 一个域复位释放后直接扇出到所有域 |

**复位域（RDC）是独立于 CDC 的一类缺陷**：两个模块在同一时钟域但复位不同源，会出现"A 已复位、B 还在跑"的窗口，此时 B 送给 A 的控制信号会把 A 从复位态里拽出来。检查方法：按**复位源**分组，看有没有跨组的信号通路没有隔离。

规则：

- **复位释放顺序要写进 spec**。谁先释放、释放前是否需要另一域稳定，必须明确。
- **异步复位同步释放**是常态，两级的第二级输出才是复位信号本身，别把第一级拿去用。
- 软复位只复位数据通路与状态机，**不复位配置寄存器**（否则软件写完配置一软复位就丢）；要不要复位配置必须写清。
- 跨电源域的复位信号需要 level shifter，跨域的复位还需要 isolation。

## 4. 中断汇聚

**中断控制器是整个芯片里最容易"看起来对、实际漏"的模块**，因为它只在异常时工作。

| 项 | 做法 | 缺陷形态 |
|---|---|---|
| 触发类型 | 电平（level）优先，边沿（edge）只在源头是真脉冲时用 | 边沿中断在清之前又来一次 → 丢失 |
| 清除方式 | `W1C`（写 1 清），且清除要与新事件竞争安全 | 读改写导致清掉别人的事件 |
| 聚合 | 每个源一路 status，OR 成一根 `irq` 到 CPU | 只有一根 irq，软件无法定位源 |
| 屏蔽 | mask 在**聚合前**生效 | mask 在聚合后 → 屏蔽了但 status 还在涨 |
| 唤醒 | 低功耗域的中断要能唤醒 CPU，标记为 wakeup 源 | 中断来了但 CPU 在 retention，永远不醒 |

**中断风暴的防护**：高频事件源（如 DMA 完成、每个包一个中断）必须做**计数聚合**或**中断合并（coalescing）**，否则 CPU 100% 在进中断。规则：同一源在 N 个周期内的 M 次事件合并为一次中断，把计数放在 status 里让软件读走。这个 N/M 要写进 spec，不能"看情况"。

**清中断与新事件同时发生**是必测场景：`W1C` 逻辑必须是 `status <= status & ~wr_clear`，而不是 `status <= 0`。后者会把清的那一拍新到的事件一起清掉。

## 5. 低功耗域

跨电源域的信号有四种处理件，缺一个就是硅上的浮空或漏电：

| 处理件 | 加在哪 | 不加的后果 |
|---|---|---|
| **Isolation cell** | 关断域 → 常开域的输出 | 关断后信号浮空，常开域收到不定态，静态电流飙升甚至功能错乱 |
| **Retention flop** | 关断域内需要保状态的关键寄存器 | 关断即丢状态，唤醒后要重新配置 |
| **Level shifter** | 不同电压域之间 | 低电压驱动高电压，高电压侧认不到，或长期可靠性退化 |
| **Power switch** | 域的电源入口 | 域关不掉 |

**隔离的默认值要选对**：给下游"无效"的值。握手信号默认 0（`valid=0`、`ready=0`），中断默认 0，复位默认有效。默认值给错，关断域一断，下游就以为有事务来了。

**关断顺序**：先让域内停止发起事务 → 等 outstanding 事务全部返回（这步最容易漏，写还没回就断，数据丢）→ 加隔离 → 关时钟 → 关电源。**上电顺序反过来**：先上电 → 放时钟 → 撤隔离 → 释放复位 → 域内初始化。

`isolation` 和 `retention` 的粒度、`level shifter` 的位置，都是**后端物理实现**必须提前知道的信息——集成阶段就要出这张表交给后端，不能等布局布线时才发现有跨域线没处理。

| 信号名 | 源域 | 目的域 | 处理件 | 隔离默认值 | 备注 |
|---|---|---|---|---|---|
| `u_dsp__irq` | DSP(可关断) | AON | isolation | 0 | 关断时不上报中断 |
| `u_dsp__cfg_*` | AON | DSP(可关断) | level shifter | — | 1.0V → 0.8V |

## 6. 互连拓扑的取舍

| 拓扑 | 面积 | 带宽 | 适用 | 代价 |
|---|---|---|---|---|
| 共享总线（AHB） | 最小 | 全部 master 抢一条 | master 少、带宽需求低 | 仲裁延迟随 master 数线性涨 |
| Crossbar | ≈ 面积 ∝ master × slave × 位宽 | 每对 master-slave 独立 | 中等规模、并发需求明确 | 面积随对数平方增长，布线拥塞 |
| NoC | 介于两者（按需布线） | 可扩展 | master/slave 数 > 16、跨长距离 | 延迟增加（每跳 1–3 拍）、调试难 |

**crossbar 的面积估算**：`面积 ≈ M × S × W × 单位位面积`。16 master × 16 slave × 128 bit 的 full crossbar，交叉点就有 256 个 128 位通路，面积往往超过整个子系统。所以**实际做法是部分 crossbar**：只给真正需要并发的 master-slave 对开直连，其余走共享通道。哪些对需要直连，由数据流分析给，不能靠"都给上，反正灵活"。

**仲裁**：round-robin 保证公平但最坏延迟不可控；固定优先级延迟可控但会饿死低优先级。**实时性要求高的 master 要单独给 QoS 或独立通路**，不要指望仲裁器照顾它。

## 7. 集成自检清单

- [ ] 地址表齐备，无重叠、无未声明空洞，**default slave 存在且返回 DECERR**
- [ ] 每个 slave 的 base 按 size 对齐，size 是 2 的幂
- [ ] outstanding 深度由带宽与 RTT 算出，数值写在 spec 里
- [ ] 突发跨 4 KB 边界由谁拆已明确
- [ ] `AW`/`W`/`B` 三通道独立握手，无"假设同拍"逻辑
- [ ] 多 ID 乱序场景下，响应有重排或按 ID 独立缓冲
- [ ] 时钟域图完整，每个跨域点有方案，无多 bit 各自两级同步
- [ ] 复位域按源分组核对过，跨组通路有隔离
- [ ] 复位释放顺序写在 spec 里，异步复位同步释放完整
- [ ] 中断：源可定位、mask 在聚合前、`W1C` 与新事件竞争安全、高频源有合并
- [ ] 每个可关断域的输出都有 isolation，默认值给"无效"
- [ ] 关断前等 outstanding 事务返回，顺序写进流程
- [ ] 跨电压域有 level shifter，位置表交给后端
- [ ] crossbar 只连必要的 master-slave 对，面积算过

## 8. 集成阶段的常见坑

- **地址空洞没 default slave**：CPU 读一个没接的地址，总线永远不回，看门狗复位，表现为"随机死机"。
- **outstanding 拍脑袋给 8**：带宽只有理论值的 1/5，且所有报告都正常。
- **写响应没人等**：写通路几拍后堵死，读还正常，误导排查方向。
- **用一根 `irq` 直接连 CPU**：中断来了软件不知道是谁，只能全轮询。
- **清中断写 0 而不是 W1C**：清的同时丢了新事件，偶发丢中断。
- **关断域断电源前不等写返回**：数据静默丢失，无任何报错。
- **isolation 默认值给 1**：关断时下游以为握手有效，发起事务打到黑洞。
- **跨域复位各自释放**：一个域已复位另一个还在输出，复位态被拽出，概率性挂死。
- **crossbar 全连**：面积翻倍、布线拥塞，实际并发只用得到三成通路。
